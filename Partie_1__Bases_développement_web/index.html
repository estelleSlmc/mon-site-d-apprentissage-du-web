Cours suivi

Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Le web, ou World Wide Web, est un ensemble de pages accessibles depuis un lien hypertexte. Grâce aux liens hypertexte, chaque page sur le web est liée à d’autres pages.

Internet

Internet est le réseau qui permet la communication entre les ordinateurs. Sur ce réseau existe plusieurs services, tel que le web, ou les mails.

Cloud

Le cloud est un service de stockage de données fourni à travers le web.

W3C

The World Wide Web Consortium (W3C) is an international public-interest non-profit organization that develops web standards and guidelines on the principles of accessibility, internationalization, privacy and security.

Partie 2 - Distinguez les langages du Web

Langages client

Les langages client servent à fournir des informations de base pour la construction des sites web, dont ils descrivent l'apparence. Ils sont principalement Le HTML, CSS et JavaScript. On les appele aussi les langagues front-end.

Navigateurs

Le navigateur traduit les langages HTML, CSS et JavaScript sous la forme de sites web utilisables par tout le monde.

Langages serveur

Les languages serveur vont servir à décrire comment un site web doit se comporter. Il en existe plusiuers : PHP, Python, c# sont parmis les plus courants.

Frameworks

Un framework est architecture de code pré-faite avec des modèles standardisés, pour faciliter et accélérer le développement. Chaque langagues back-end à son framework.

Bases de données

Une base de données est un logiciel dédié au stockage de données. Il en existe plusieurs, et pour communiquer avec ces logiciels, on utilise un languages SQL.

Site responsive

Un site responsive est un site web dont l'affichage s'adapte à la taille de l'écran (ordinateurs, tablette, télphone).

Application mobile

L'application mobile, ou bien l'application « native », est conçue spécialement et uniquement pour un smartphone ou une tablette. Cette option est plus lourde mais elle offre une meilleure expérience pour un service complexe. Elle se développe avec des langages mobiles spécifiques à Android et IOS (par exemple : Kotlin, Java ou Swift.)

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Les serveurs sont les machines qui possèdent les sites web et qui les distribuent aux clients.

Adresse IP

Chaque ordinateur possède une adresse. On parle d’adresse IP. Elle se présente comme une suite de nombre.

Nom d’hôte et DNS

Le nom d'hôte est le nom du site/service que l'on souhaite utiliser. Le DNS permet de traduire le nom d’hôte en adresse IP, il fonctionne comme un annuaire.

Protocoles

Le protocole est le langague de communication qui permet aux machines de parler entre elles. Il exite les protocoles de bas niveaux (TCP, UDP), et les protocoles de haut niveaux (HTTP, HTTPS, FTP, SMTP).

Partie 4 - Identifiez les métiers du web

Développeurs

Le développeur est une personne qui conçoit, teste, documente et maintient des applications, des sites Internet ou des logiciels. Il existe plusieurs spécialisations possibles comme le front-end, back-end, mobile ou encore low-code.

Product Managers et chefs de projets

Le product manager assure que le produit évolue dans la bonne direction, en anticipant les besoins futurs et en définissant une stratégie à long terme. Il collabore avec les équipes marketing et est responsable de la rentabilité du produit et de son évolution à long terme.

Designers

Les designers sont chargés de concevoir un site ou une application avec une utilisation ergonomique qui répont aux besoins et attentes de l'utilisateur. L'UX designer va se concentrer sur la partie focntionnalité alors que l'UI designer conçoit l'interface.

Testeurs

Le testeur est chargé de concevoir, d'exécuter et d'automatiser les tests pour garantir la qualité des logiciels ou des produits. Il identifie les bugs et les problèmes de performance afin de les résoudre avant la mise en production.

Techniciens informatique

Le technicein informatique s'occupe de la gestion du parc informatique, du support technique et de l'accès aux services réseaux des entreprises.

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Permet de styliser et de mettre en page le contenu (couleurs, polices, design responsive).

JavaScript

Front-End

permet de rendre les pages web interactives en ajoutant des fonctionnalités dynamiques et en réagissant aux actions de l'utilisateur.

JavaScript

Back-End

Le développeur peut écrire en JavaScript avec NodeJS, ce qui lui permt de faire du full-stack sans avoir besoin d'apprendre un nouveau language.

PHP

Back-End

PHP est un langage de script côté serveur utilisé pour générer du contenu dynamique sur les sites web. Il est souvent intégré dans du code HTML.

Java

Back-End

langage de programmation polyvalent, orienté objet, fondé sur le principe "Écrire une fois, exécuter partout", qui permet au code de s’exécuter sur n’importe quelle plateforme disposant d’une JVM.

Python

Back-End

Language polyvalent qui permet de créer des logiciels, analyser des données, automatiser des tâches et concevoir des sites web.

C#

Back-End

Proche du Java, il est utilisé pour développer des applications web, des applications de bureau, des services web, des commandes, des widgets ou des bibliothèques de classes.

SQL

Bases de données

Le SQL est un langage informatique standardisé qui sert à communiquer, exploiter et gérer des bases de données relationnelles.

Boîte à outils du développeur

  • IDE comme VS Code : Editeur de texte
  • Github : Service en ligne qui héberge les dépôts Git.
  • Librairies / bibliothèques : une collection de code préécrit, de fonctions, de classes ou de routines que les développeurs peuvent réutiliser dans leurs programmes.
  • Frameworks : architecture de code pré-faite avec des modèles standardisés selon produit.
    exemple : Symphony pour PHP, Django pour Python, ASP.NET pour C#
